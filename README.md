## Description 
A website that allows users to create an account to trade with other users. These trades can include physical products such as crocheted items, tattoos, or other creative projects. Users can post listings and add a description, images of their work, and what they're looking for in return. Users looking to trade can go to the marketplace and filter by location and what items or services they're looking for.
> 

## App Functions
1. User:
   1. Create / Modify User Profile: When user clicks the webiste, there will be a button to create a user profile. This will require the user to enter their legal name, email address, create a username, and a strong password (8+ characters).
   2. Create / View Available Listings: After an account is created, there will be a button that states "Create a Listing" that will redirect to allow the user to list a desctiption and post photos of work/ item available. User can add tags to reach correct audience. Beside the posting, it will show the user and their star ratings.
   3. Subscribe to available services: Users will be able to chat with poster when they click a listing. The chat will be created with the poster, user, and listing all inside the chat.
   4. Reviews: Each user can rate the other user after a trade is complete. This will include a star rating along with an optional description of how the trade went. The users leaving reviews can opt to make the review anonymous to avoid conflicts.
