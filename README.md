## Description 
A website that allows users to create an account to trade with other users. These trades can include physical products such as crocheted items, tattoos, or other creative projects. Users can post listings and add a description, images of their work, and what they're looking for in return. Users looking to trade can go to the marketplace and filter by location and what items or services they're looking for.
> The users will also have the option to rate each other after the trade has been completed. This will be done via a star rating and a breif description based on how it went. The user will also have the option to mark as anonymous when leaving the review for safety reasons. Each user will have the option to reach out and contact mods or admins for any issues with the website or issues with another user. Mods will try to handle these issues the best they can and if they cannot resolve the issue, it will be pushed to Admins who will have chat logs and data from all parts of the trade to resolve the issue.

## App Functions
1. User:
   1. Create / Modify User Profile: When user clicks the webiste, there will be a button to create a user profile. This will require the user to enter their legal name, email address, create a username, and a strong password (8+ characters).
   2. Create / View Available Listings: After an account is created, there will be a button that states "Create a Listing" that will redirect to allow the user to list a desctiption and post photos of work/ item available. User can add tags to reach correct audience. Beside the posting, it will show the user and their star ratings.
   3. Subscribe to available services: Users will be able to chat with poster when they click a listing. The chat will be created with the poster, user, and listing all inside the chat.
   4. Reviews: Each user can rate the other user after a trade is complete. This will include a star rating along with an optional description of how the trade went. The users leaving reviews can opt to make the review anonymous to avoid conflicts.
3. SysAdmin (the user with the admin role if applicable):
    1. Manage user access : The admins will be able to suspend a user or ban a user if they violate terms of service.
    2. Moderate services : Admins have the option to change, modify, or remove any posting that is made by users for TOS reasons. 
    3. Moderate reviews - If a user feels that they were left a bad review and do not deserve it, they can reach out to admins to look into it. Admins will reach out to the person who left the review and ask why, and will then read back all the chat logs to see if both sides of the story are true. If it is found the review was left in place of malice, the admins will be able to remove it and issue infractions on the other who left said review.
    4. View usage statistics - There will be a data list that gets sent to the admins that show how many postings were made, how many new users were created, and how many of the postings created were successfully completed. Based on this data, we can try to make changes to better support the users to influence more traffic or do more to reach new users via advertising changes made.
