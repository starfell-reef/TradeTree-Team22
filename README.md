## Description 
A website that allows users to create an account to trade with other users. These trades can include physical products such as crocheted items, tattoos, or other creative projects. Users can post listings and add a description, images of their work, and what they're looking for in return. Users looking to trade can go to the marketplace and filter by location and what items or services they're looking for. The trade will include a private chat between users to agree upon a time and place. After a trade is complete the users have the option to leave reviews of the other trader. Reviews will include a star rating and optional description of how everything went. The user leaving a review will have the option to remain anonymous. If users have any issues they may reach out to system admins to resolve the issue. 

## App Functions
1. User:
   1. Create / Modify User Profile: When user clicks the webiste, there will be a button to create a user profile. This will require the user to enter their legal name, email address, create a username, and a strong password (8+ characters).
   2. Create / View Available Listings: After an account is created, there will be a button that states "Create a Listing" that will redirect to allow the user to list a desctiption and post photos of work/ item available. User can add tags to reach correct audience. Beside the posting, it will show the user and their star ratings.
   3. Subscribe to available services: Users will be able to chat with poster when they click a listing. The chat will be created with the poster, user, and listing all inside the chat.
   4. Reviews: Each user can rate the other user after a trade is complete. This will include a star rating along with an optional description of how the trade went. The users leaving reviews can opt to make the review anonymous to avoid conflicts.
3. SysAdmin (the user with the admin role if applicable):
    1. Manage user access - If a user is reported for scam, robbings, or threats then the admins can erase or suspend the account based on the severity of the infraction.
    2. Moderate services - Admins can see all listings created and are able to remove them if deemed against terms of service.
    3. Moderate reviews - If a user reaches out about a review left they do not agree with, they can reach out to an admin to investigate and remove the rating if found to be a false rating. This will inlcude the admin reaching out to the user who left the review. 
    4. View usage statistics - Admins will get a report on how many listings are made each week and how many of those listings are completed. We can use this information to make changes based on location radius, or how the setup of listings are to ensure the best experience and use of our site.
